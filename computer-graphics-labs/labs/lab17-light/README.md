# lab17-light

对应书中第 17 章：光源模型。

## 学习目标

- 点光 / 方向光 / 聚光灯 / 面光源四种光源模型
- 距离平方衰减 `I / (1 + k·d²)` 与聚光锥 smoothstep 掩码
- 面光源采样：对光上多点求可见性与贡献的均值 → 软阴影（半影）
- 多光源叠加

## 关键公式

- 点/聚光衰减：`att = intensity / (1 + 0.09·d²)`
- 聚光掩码：`mask = smoothstep(cos_outer, cos_inner, cosθ)`
- 面光源（直接光近似）：`L ≈ (1/N) Σ_i brdf·ndotl·att(p→l_i)·V(p↔l_i)`，采样点 `l_i` 在光源矩形上均匀抽取
- 点光是 delta 光源：单次可见性测试 → 硬阴影；面光源是分布光源：多点平均 → 软阴影

## 编译运行

```powershell
mingw32-make -C labs/lab17-light run
```

输出：`out/lab17_light.ppm`（四球 + 地面，四种光源同时作用于全场景）。

预期现象：

- 点光与聚光灯下的阴影边缘锐利（硬阴影）；
- 右侧球下方是面光源，阴影有渐变的半影，离遮挡物越远越软；
- 点光附近亮、远处暗，可看出距离衰减。

## 建议改动

- `--spp`（默认 32）：面光源采样数，调低会看到软阴影里的噪点（蒙特卡洛方差），调高更平滑。
- `--seed`（默认 7）：固定种子保证可复现。
- `src/main.c` 中 `area.half`：面光源尺寸，越大半影越宽。
- `--out`：输出路径。

## 自检

```powershell
mingw32-make -C labs/lab17-light test
```

覆盖：距离衰减、聚光锥衰减、面光源采样在遮挡/无遮挡线段上的可见性、面光源随距离变暗。

## 常见坑

- 面光源靠采样平均，spp 低时阴影内有噪点是正常现象（方差随 N 收敛）。
- 阴影射线要用线段范围（t < dist-ε）而不是无限射线，否则会误判光源自身/远处的物体。
- 弧度制：`CGL_PI/180` 转换角度；`smoothstepf` 的两个边界参数是从小到大。
