# Lab 04 — 随机信号与维纳滤波

对应路线图第 4 章。Box-Muller 高斯噪声、目标 SNR 加噪、频域维纳、AR(1)。

## 知识点

1. 随机过程的基本量：均值/方差/自相关；SNR 的统计定义（功率比）。
2. Box-Muller 变换：两个独立均匀随机数 → 一对独立高斯数，极坐标形式的数值边界处理。
3. 统计检验的严谨性：单次样本均值的 z 分数（μ/(σ/√N)）本身是 N(0,1) —— 任何"过紧"的固定界都会变成种子抽奖。
4. 按目标 SNR 精确加噪：由信号功率与目标 SNR 反推噪声方差（封装为工具函数，第 6-8 章复用）。
5. 频域维纳滤波 H(ω)=Ps/(Ps+Pn)：已知 Ps/Pn 时的最优均方意义降噪。
6. 无先验信息的代价：用噪声谱减法从 noisy 估计 Ps，χ² 起伏直接泄漏进增益 —— 增益显著低于 oracle 版（实测 5.7 vs 13.7 dB）。
7. AR(1) 有色噪声：y[n]=a·y[n−1]+e[n]，功率谱随 a 呈低通/高通形。

## 过关判据

| 指标 | 判据 |
|------|------|
| 高斯统计 | 10 段独立 20k 样本：合并 \|z\| < 2（95% CI）且单段 \|z\| < 3（见下方放宽说明） |
| 高斯方差 | \|σ−1\| < 0.02 |
| AR(1) 谱 | 低/高频能量比 > 4（有色性） |
| 维纳降噪（oracle） | 已知 Ps/Pn，输入 0 dB 时输出 SNR 提升 ≥ 3 dB |
| 维纳降噪（估计 Ps） | 从 noisy 谱减得到 Ps（无 clean 参考）：增益 ≥ 0 且严格低于 oracle —— 量化"无先验为什么做不到" |

## 局部放宽（S4 合同 4）

- 路线图原文界 `\|μ\| < 0.05·σ/√N` 是 0.05 个标准误的界：对无偏生成器，任何单次抽取的先验通过率只有约 4%，逐种子凑答案没有统计意义。硬门改为 **10 段独立样本的合并 z 分数 < 2**（等价于均值无偏的 95% 置信检验），每段的路线图字面量照常打印供对照。原 `out/findseed.*` 工具已删除。
