# 编译原理配套实战 Lab（对照《编译原理》龙书第 2 版）

这是一套**最小化、可运行、带详细中文注释**的编译器实验系列。
每个 lab 都是一个独立小程序，严格对照龙书（《编译原理：原理、技术与工具》第 2 版）的章节顺序，
从"100 行的翻译玩具"一路长成"能做词法分析、语法分析的真实编译器前端"。

> 定位：**不是工业级编译器**，而是把龙书里的每一段理论（算法 3.20、FIRST/FOLLOW 不动点、
> LR(0) 项目集规范族……）变成你能单步观察、动手修改的活代码。

## 环境要求

- **gcc**（本仓库按 MSYS2 UCRT64 的 gcc 16 验证；任何较新的 gcc/clang 均可）
- **bash**（Git Bash / MSYS2 自带的 bash，用于跑测试脚本）
- 无任何第三方依赖

在 Git Bash 中确认环境：

```bash
gcc --version        # 应输出 gcc 版本
```

## 每个 lab 的统一玩法

```
labX-xxx/
├── README.md      # ① 先读：理论精要 + 代码导读 + 练习 + "龙书 vs 现代"勘误
├── src/           # ② 再看：带逐行中文注释的 C11 源码
├── tests/         # ③ 最后跑：对拍测试
│   ├── cases/     #    测试输入与期望输出
│   └── run_tests.sh
└── Makefile
```

构建与测试（以 lab1 为例）：

```bash
cd lab1-lexer
mingw32-make          # 或者：gcc -std=c11 -Wall -Wextra -O2 -o minilex.exe src/*.c
./minilex.exe tests/cases/demo.mc
bash tests/run_tests.sh
```

> 没有 `make` 时直接用上面的 gcc 一行命令即可；`run_tests.sh` 内部也是这么编译的。

## 建议的学习节奏

1. **读 lab 的 README**，对照龙书对应章节过一遍理论；
2. **跑通 demo**，看看输入输出；
3. **加 `-v` / `-trace` 类开关重跑**，观察内部数据结构（token 流、分析栈、DFA 状态……）——
   这一步是把抽象算法"变成自己的"的关键；
4. **做 README 末尾的练习**（改文法、加运算符、故意制造冲突……）；
5. 跑 `run_tests.sh` 确认你的修改没有破坏正确性。

## 本套实验贯穿的"MiniC"语言

所有 lab 围绕一门逐 lab 长大的 C 子集语言 **MiniC** 展开：

- lab1：只要求**词法上**合法（标识符、关键字、整/浮点字面量、运算符、注释）；
- lab3：`print 表达式;` 与 `表达式;`，运算符优先级同 C（关系 < 加减 < 乘除模 < 一元负号）；
- lab4：加入 `if (表达式) 语句 [else 语句]`、`{ }` 块与空语句——专门用来演示悬空 else 冲突；
- lab5：加入变量声明（可初始化）、赋值、`while/break/continue`、块级作用域与
  `int/float` 类型检查（隐式提升 `i2f`、禁止隐式收窄）；分析结果物化为 AST，
  检查通过后树遍解释执行；
- lab6：加入函数定义/调用/参数/`return`（值传递、支持递归）、`&& || !` 短路
  布尔与**一维数组**（6.4 节：取址四元式 + 数组描述符；不作函数参数/返回值、
  声明即零初始化）；编译到四元式（回填/条件跳转），默认由 IR 解释器执行，
  树遍执行保留为 `-eval` 对照；
- lab7：执行引擎换成显式活动记录的**栈式虚拟机**——真实调用栈、
  返回地址、形参住进帧内槽位（fp+offset），无穷递归从段错误变成"栈溢出"报错；
  树遍（`-eval`）与 C 递归解释器（`-irvm`）保留为对照，三引擎对拍；
- lab8：后端落地成真机器——四元式生成 **x86-64 汇编**（Windows x64 ABI），
  `gcc prog.s rt.c` 链接成真正的 .exe；数组变成一条变址寻址，除零检查
  进运行时库；四种后端（x86-64/vm/irvm/eval）输出一致。
- lab9：`-O` 点亮**优化器**——常量折叠与传播、局部公共子表达式消除、
  活跃变量分析（数据流不动点）驱动的死代码删除、窥孔清理；带 -O 跑完
  原生管线，输出仍与 lab3~lab8 的期望逐字节一致。
- lab10：加入 `for (init; cond; step)` 循环——parser 直接拼装降糖为既有 AST
  组合（等价 `{ init; while (cond) { body; step; } }`），gen 与四个执行引擎
  零改动；循环级优化（不变量外提、计数循环展开）与 `-cfg` 观测随本 lab 落地。
- lab11：加入**二维数组** `int m[N][M]`——gen 层行主序扁平化降糖
  （`m[i][j]` → `t=i*M; t2=t+j; v=m[t2]`），四个执行引擎零改动；依赖分析
  （距离向量 + `-deps`/`-space` 观测）随之落地：展开升级为"依赖检查通过才
  展开"并解禁数组写体，完美嵌套支持循环交换。
- lab12：**语言冻结在 lab11 状态**，过程间分析全部落在 IR 层——`-cg`
  调用图、函数内联（PARAM 回扫配对/临时重编号/标号按次重映射）、形参
  must 交集迭代代入（IPCP 简化版）、mod/ref 集合精确化四处 CALL 保守
  门禁；前端/gen 层与四个执行引擎零改动。至此本套 lab 走完龙书正文的
  全部主线。
