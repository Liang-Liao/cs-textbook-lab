# 第 14 章：动态规划（Dynamic Programming）

对应《算法导论》第三版第 14 章（书中编号为第 15 章）。实现钢条切割、矩阵链乘、LCS 与最优 BST。

## 本章算法

| 算法 | 书中节号 | 源文件 |
|------|----------|--------|
| 钢条切割（自底向上 / 记忆化） | 15.1 | `dp.c` |
| 矩阵链乘最优括号化 | 15.2 | `dp.c` |
| 最长公共子序列 | 15.4 | `dp.c` |
| 最优二叉搜索树 | 15.5 | `dp.c` |

## 实现说明

- 钢条：`price[i-1]` 为长度 `i` 的售价；自顶向下与自底向上结果一致。
- 矩阵链：`dims` 长度为 `n+1`，A_i 为 `dims[i]×dims[i+1]`（0-based）。
- LCS：返回长度，可回溯一个 LCS 字符串。
- 最优 BST：`p[0..n-1]` 键概率，`q[0..n]` 虚键概率；半开区间 DP；书中例子代价 **2.75**。

## 阅读建议

1. 最优子结构 + 重叠子问题 → 可用 DP；钢条的 `r[n]` 递推。
2. 矩阵链为何不能贪心；`m[i,j]` 枚举断点 `k`。
3. LCS 的 `c[i,j]` 与方向表回溯。
