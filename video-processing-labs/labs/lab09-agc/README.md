# Lab 09 — AGC 与动态范围

对应路线图第 9 章。静态压缩器、AGC 环路、前瞻软限幅器、LUFS 量化。

## 过关判据

| 指标 | 判据 |
|------|------|
| 压缩器曲线 | 扫幅正弦 -60..0 dBFS 逐点对账解析静态曲线（门限/比率/软拐点/makeup），偏差 ≤ 0.5 dB（实测 ~0） |
| AGC 收敛 | 20 dB 电平跳变后 ≤ 1 s 内到目标 ±2 dB（硬断言） |
| AGC+限幅器串联 | 大信号（-1 dBFS 段）下输出削波样本数 == 0（真实 0 dBFS 边界），峰值 < -0.1 dBFS |
| 超调 | 快攻击 (5ms) 跳变后 RMS 超调 < 12 dB 且小于慢攻击 (50ms)——攻击/释放权衡可量化对比 |
| 轻/响响度 | 两段输出 LUFS 差 ≤ 1 LU |
| LUFS 计量 | 增益 +6 dB → +6 LU ± 0.5 |

## 实现说明

- 压缩器：`compressor_gain_db` 静态曲线（二次软拐点，边界连续）；`compressor_run_sample` 用调用方跟踪的峰值包络（`out/compressor_curve.csv` 落盘对账数据）。
- AGC：整流包络 + 攻击/释放非对称增益平滑 + 增益限幅；`peak_limit=0.99` 是 AGC 模块自身的安全硬限（最后防线）。
- **前瞻软限幅器**：包络跟随**未延迟**输入（提前看到峰值）→ 期望增益 = min(1, limit/env) → 攻击/释放平滑 → 作用于延迟 5 ms 的信号。峰值到达输出时增益已压下，砖墙钳位（0.999）永不触发——"削波数 = 0"由增益整形真实达成，不靠硬削波恒真化。
- 超调用跳变后 150 ms 的 RMS 轨迹度量（峰值会被安全硬限钳住，RMS 才反映增益动态）：快攻击 -0.45 dB vs 慢攻击 +4.95 dB。
- LUFS：BS.1770 高架 + RLB 高通 K 加权、400 ms 块 75% 重叠、绝对 -70 + 相对 -10 LU 双门。
