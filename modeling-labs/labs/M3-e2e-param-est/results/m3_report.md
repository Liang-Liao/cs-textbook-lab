# M3 端到端参数估计报告

## 配置

- 模型: Lotka-Volterra
- 真参数 θ: (1, 0.08, 0.6, 0.04)
- y0 = (12, 4), t ∈ [0, 18], n_obs=25, σ=0.7, h_ode=0.05
- 点估计: M2 式混合（DE rand/1 → 缩小盒 DE best/1 → Nelder-Mead），budget 次评估
