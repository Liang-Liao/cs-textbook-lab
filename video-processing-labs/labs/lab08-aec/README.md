# Lab 08 — AEC

对应路线图第 8 章。FFT 互相关延迟估计、NLMS、双讲检测/冻结、NLP、μ 扫描、PBFDAF、ERLE。

## 过关判据

| 指标 | 判据 |
|------|------|
| 闭环单讲 ERLE | ≥ 20 dB（FFT-xcorr 对齐后） |
| 延迟估计 | 采样点级误差 0（已知合成延迟） |
| 双讲检测 | 查全率 ≥ 0.6（对真值窗口）；hangover ≤ 一个 DT 时长（不许永久锁死） |
| 双讲冻结 | 冻结 vs 不冻结对 h 的破坏可量化，且冻结滤波器 DT 后重收敛（‖h_err‖ ≤ 0.1） |
| NLP | 单讲段 NLP 后 ERLE ≥ 20 dB 且比线性 AEC 多 ≥ 3 dB 抑制；双讲近端损伤 ≤ 1 dB |
| PBFDAF | L=512（4×128 分区）稳态 ERLE ≥ 15 dB；耗时 ≤ NLMS（实测 ~4×） |

## 实现说明

- 延迟估计：频域互相关（FFT of `d * conj(x)`），峰值即相对延迟。
- 闭环：`estimate_delay` → 对齐参考 → NLMS → 测稳态 ERLE。
- **双讲检测**：信号驱动（不用真值）。块级能量比 `r = Σe²/Σŷ²`（ŷ = 麦克风 − AEC 残差，即自适应滤波器自己的回声估计）+ 最小值跟踪校准：DT 阈值 = max(15·β, 0.05)，β 取最近 32 块 r 的最小值（收敛后的残差底）。高残差有歧义（近端语音 vs 滤波器未收敛），连续冻结 12 块后放行 1 个探测块并看残差趋势：下降 → 恢复中（继续适应），平 → 真 DT（重新冻结）。块级池化能量比而非逐样本比值——逐样本 `e²/ŷ²` 在远端包络低谷处发散，块均值被重尾污染。
- **NLP**：残差与其回声估计比较：`r = err²/(resid_ratio·ŷ²)`，r ≤ 0.3 → 压到 floor（-10.5 dB），r ≥ 1 → 近端直通。抑制方向必须"残差占比越高压得越狠"。
- μ 扫描：打印 μ ∈ {0.1,0.3,0.5,0.7,0.9} 的稳态 ERLE 与失配，写 `out/mu_sweep.csv` 与收敛曲线 `out/convergence.pgm`。
- **PBFDAF**：overlap-save 分块频域 NLMS，P 分区 × M 抽头；归一化用**跨分区总功率**（逐分区归一化在 P=4 时不稳定，会发散）；每块对各分区做时域约束（保留前 M 点）。FFT 用本 lab 内演化的迭代 radix-2（`fft_iter`，复用 lab02 递归版仅用于延迟估计——递归版每 FFT ~320 µs，11 FFT/块时占满整个时间预算，迭代版让 PBFDAF 对 NLMS 提速 ~4×）。

## 局部放宽（S4 合同 4 记录）

- 路线图 PBFDAF 实验写"长路径（512+ 抽头）"：已按 512 抽头实现（4×128 分区），无放宽。
- `synth_path` 的回声路径被整形（h[0]=1、尾 ≤ 0.04·exp(−i/τ)）：真实重尾指数衰减路径会让互相关峰偏移若干采样（尾部群延迟），"延迟误差 0"判据将无法在采样点级成立；整形保证块延迟主导互相关峰。这是对实验前提的简化，不是指标放宽。
- 近端"语音"用 300 Hz 正弦、远端用单极点滤波噪声：合成简化（零外部依赖），判据口径不变。
