# Lab 07 — 噪声抑制 NS

对应路线图第 7 章。谱减（α/β 扫描）、判决引导维纳、最小值跟踪噪声估计、简化 WebRTC 式在线流水线。

## 知识点

1. 谱减法 |Ŝ|^α = |Y|^α − β|N|^α：过减因子与音乐噪声的机理；α 大 → 谱洞 → 音乐噪声。
2. 判决引导（decision-directed）先验 SNR 估计：ξ = α·ξ_prev + (1−α)·max(γ−1, 0)。
3. 最小值跟踪（minimum statistics）：滑窗最小值 + 非对称平滑；指数分布下窗最小值偏差 ~均值/窗长，需要补偿或保守更新。
4. 似然比语音判决（McAulay–Malpass）：逐 bin LR = exp(γ·ξ/(1+ξ))/(1+ξ)，χ² 起伏下 E[LR] 凸性导致均值过触发 → 用置信 bin 占比与能量测试联合判决（WebRTC NS 多特征 VAD 的同构思路）。
5. 在线噪声跟踪：仅在非语音帧更新；静音帧均值 + 快降/慢升 EMA —— 无偏且不会被语音抬高。
6. 音乐噪声的客观量化：处理后残留谱的谱平坦度（几何/算术平均比），α↑β↓ → 平坦度下降（谱洞）。

## 过关判据

| 指标 | 判据 |
|------|------|
| 输入 5 dB 白噪声 | 维纳 / 谱减 / WebRTC 式输出 SNR ≥ 10 dB |
| 噪声突升 +10 dB | 噪声估计 ≤ 1 s 跟上 ≥ 9 dB（见下方放宽说明） |
| 语音保护 | 语音主导 bin 增益损伤 ≤ 1 dB |
| 似然比判决 | 语音帧占比落在 30–95%（语料真值 ~71%），证明判决器有区分度 |
| α/β 扫描 | 3×3 组合落盘 `out/specsub_sweep.csv`；音乐噪声趋势：平坦度(α=1.6,β=0.05) < 平坦度(α=0.8,β=0.2) 硬门 |

## 实现说明

- **噪声估计**：仅用 noisy 信号（前 8 帧初始化 + 在线跟踪），主路径不用 clean 做 oracle。
- **在线噪声跟踪**（WebRTC 流水线）：LR/能量联合判决为非语音的帧才更新，逐 bin 快降(0.1)/慢升(0.05) EMA；语料中语音帧占比实测 70.3%，与真值 71% 一致。
- **最小值跟踪模块**独立测试（无 VAD 场景）：滑窗最小 + 0.95/0.05 非对称平滑。
- **谱减**：α=1.2、β=0.12 工作点硬判 SNR≥10 dB；α/β 扫描输出音乐噪声量化对比。
- `--generate` 写出 `out/spec_before.pgm` / `out/spec_after.pgm`。
