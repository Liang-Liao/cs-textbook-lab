# Lab 05 — 听觉特征

对应路线图第 5 章。Mel 三角滤波组、Mel 谱热图、简化 LUFS（K 加权 + 门限）、双音掩蔽客观幅度扫描。

## 知识点

1. 响度/音调/音色的信号学对应；音调与基频 f0 的关系。
2. 频率掩蔽与时域掩蔽：感知编码（第 16 章）的理论根基。
3. 临界频带与 Bark 尺度：z(f)=13·atan(0.00076f)+3.5·atan((f/7500)²)。
4. Mel 尺度 mel=2595·log10(1+f/700) 与三角滤波器组的构造。
5. LUFS（EBU R128）：K 加权（高架 + RLB 高通）、400ms 块 75% 重叠、绝对 −70 + 相对 −10 LU 双门。
6. 掩蔽阈的扩展函数近似：随 Bark 距离衰减（本 lab 用 −27 dB/Bark），阈值随临界频带距离单调上升。

## 构建与运行

```bash
make && make test && make run
```

## 过关判据

| 指标 | 判据 |
|------|------|
| Mel 中心 | 单调递增，符合 mel=2595·log10(1+f/700)（逐滤波器偏差 < 1 mel），覆盖 0–8 kHz |
| LUFS 增益 | 同信号 +6 dB → LUFS +6±0.5 LU |
| 掩蔽扫描 | 带内探针（1125 Hz）阈值 > 0；临界频带排序：1400 Hz（远离掩蔽器）阈值 < 带内阈值的 1/10 |
