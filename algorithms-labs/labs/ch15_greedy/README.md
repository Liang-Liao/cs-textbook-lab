# 第 15 章：贪心算法（Greedy Algorithms）

对应《算法导论》第三版第 16 章（第二版第 15 章，本目录沿用两位章号命名）。实现活动选择、分数背包与 Huffman 编码。

| 算法 | 书中节号 | 源文件 |
|------|----------|--------|
| 活动选择（最早结束时间） | 16.1 | `greedy.c` |

## 实现说明

- 活动选择：先按结束时间排序，再从左到右选相容活动；输出为排序后下标。
- 分数背包：按价值/重量降序装入，可部分取。
- Huffman：每次合并最小两棵子树；测试校验书中例子 WPL=224。

3. Huffman 前缀码与最优编码的关系。
