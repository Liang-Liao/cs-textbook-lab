# Lab 13 — 运动估计（块匹配）

全搜索 / 三步法（TSS）/ 菱形搜索、半像素运动补偿、MV 场可视化。

## 知识点

1. **块匹配 ME**：在参考帧搜索窗内，对当前帧每个块找使 SAD（或 SSD）最小的位移向量。
2. **全搜索**：遍历 `[-R,R]²` 全部候选，精度最优，代价 O((2R+1)²)。
3. **三步法 TSS**（Koga 1981）：初始步长 `2^{⌊log2 R⌋}`，每步在当前最优的 8 邻域探测，步长减半，直至 1。代价约 O(8·log2 R)，是经典快速搜索。
4. **菱形搜索**：大菱形模板迭代到不动点，再换小菱形；对大位移常比 TSS 更稳。
5. **运动补偿**：整数 MV 直接拷贝；半像素 MV 用双线性重采样，残差能量应不高于整数。
6. **MV 可视化**：把每个块的 (dx,dy) 映射到 R/G 通道写成 PPM/PGM。

## 运行

```bash
make && make test   # selftest + 写出 out/mv_field.ppm
make run            # 仅生成 MV 场与参考/当前帧
```

## 过关判据

| 指标 | 判据 |
|------|------|
| 纯平移恢复（full） | 误差 ≤ 1 像素 |
| 小位移 TSS | 块恢复率 ≥ 0.85（max_err 仅信息打印） |
| 大位移 + 大搜索窗（R=15, shift=(8,-8)） | TSS 相对 full 加速 ≥ 10× |
| 同上恢复率 | TSS ≥ 0.90；diamond ≥ 0.70 |
| 半像素 | 误差 ≤ 0.5 px，残差能量 ≤ 整数 |
