# lab15-curves

对应书中第 15 章：曲线（Bezier / de Casteljau）。

## 学习目标

- 三次 Bezier 求值
- de Casteljau 与直接公式一致性
- 一阶/二阶导数与曲率可视化
- 绘制控制多边形与曲线，显示切线方向

## 关键公式

- `B'(t) = 3u²(P1−P0) + 6ut(P2−P1) + 3t²(P3−P2)`，`u = 1−t`
- `B''(t) = 6u(P2−2P1+P0) + 6t(P3−2P2+P1)`
- 有符号曲率 `κ = (x'y'' − y'x'') / (x'²+y'²)^{3/2}`；圆的曲率 = 1/半径。

## 编译运行

```powershell
mingw32-make -C labs/lab15-curves run
```

输出：`out/lab15_curves.ppm`——曲线按 |κ| 归一化着色与加粗：蓝色细段 = 平坦，红色粗段 = 弯曲大；青色短箭头为采样点切线（解析 `B'(t)`，非有限差分）。

预期现象：本曲线两端弯曲最大（红、粗），中段接近直线（蓝、细）；曲率最大处与切线箭头方向变化最快的位置一致。

## 建议改动

- `src/main.c` 中控制点 `p[4]`：把 P1、P2 拉成与 P0/P3 共线，观察曲线变直（κ→0）。
- 采样步数 400、箭头间隔 40。

## 自检

```powershell
mingw32-make -C labs/lab15-curves test
```

覆盖：端点插值、de Casteljau 与 Bernstein 逐步一致、四分之一圆 Bezier（k=4/3(√2−1)）的 |κ(0.5)|≈1、共线控制点曲率为 0。

## 常见坑

- 图像 y 轴向下，有符号曲率的正负与纸面直觉相反，本图只映射 |κ|。
- κ 分母含 |B'|³，`B'≈0`（参数化退化）时需除零保护（代码里用 1e-9 阈值）。
- 均匀 B 样条按设计文档明确跳过，本 lab 只覆盖三次 Bezier。
